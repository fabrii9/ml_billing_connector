# Icon Placeholder

Para un módulo profesional, deberías agregar un icono PNG (128x128 o 256x256) en:

`static/description/icon.png`

Puedes:
1. Diseñar uno personalizado con el logo de Mercado Libre
2. Usar un icono genérico de "shopping" o "marketplace"
3. Descargar assets oficiales de ML (respetando sus términos de uso)

Recursos:
- Iconos gratuitos: https://www.flaticon.com/
- Generador de iconos: https://favicon.io/
- Brand assets ML: https://developers.mercadolibre.com.ar/

Mientras tanto, Odoo usará un icono por defecto si no existe este archivo.
