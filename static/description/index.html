Mercado Libre Billing Connector

Integración completa con Mercado Libre para Odoo 16

Características Principales

🔐 OAuth2 Seguro

Conexión segura con Mercado Libre mediante OAuth2. Renovación automática de tokens.

📦 Importación Automática

Importa operaciones por rango de fechas con un solo clic.

💰 Desglose Completo

Visualiza productos, comisiones, envíos, impuestos y neto a cobrar.

📄 Datos Fiscales

Obtén CUIT/DNI del comprador para facturación.

¿Qué puedes hacer?

  • Conectar tu cuenta de Mercado Libre con OAuth2
  • Importar operaciones/ventas por período
  • Ver desglose de comisiones ML y neto a cobrar
  • Obtener datos fiscales (CUIT/DNI) para facturar
  • Analizar ventas con reportes y gráficos
  • Renovación automática de tokens
  • Auditoría completa con JSON raw

Configuración Rápida

  1. Crea una aplicación en https://developers.mercadolibre.com.ar/
  2. Configura la Redirect URI: https://tu-odoo.com/ml/oauth/callback
  3. Copia Client ID y Client Secret
  4. En Odoo: Mercado Libre > Configuración > Conexión API
  5. Pega las credenciales y clic en "Conectar con Mercado Libre"
  6. ¡Listo! Ya puedes importar operaciones
